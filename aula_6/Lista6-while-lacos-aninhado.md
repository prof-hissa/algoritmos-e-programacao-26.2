# Lista de Exercícios – Laços com `while` e Laços Aninhados

---

## Parte 1 – Reescrita com `while`

---

### Exercício 1 – Refatoração com `while`

Reescreva todos os exercícios da lista anterior (laços básicos) utilizando exclusivamente o comando `while`.

Adapte:

* contagens
* somas acumuladas
* validações
* menus

Evite usar `for`.

---

## Parte 2 – Desafios com Laços Aninhados

---

### Exercício 2 – Tabuadas completas

Exiba todas as tabuadas de 1 a 10.

Exemplo de saída:

```
1 x 1 = 1
1 x 2 = 2
...
2 x 1 = 2
...
10 x 10 = 100
```

---

### Exercício 3 – Quadrado de caracteres

Peça um número N.

Exiba um quadrado N x N usando `*`.

Exemplo:

Entrada:

```
4
```

Saída:

```
****
****
****
****
```

---

### Exercício 4 – Matriz crescente dinâmica

Peça ao usuário um número N.

Exiba uma matriz N x N onde cada valor é a soma do índice da linha com o índice da coluna.

Exemplo:

Entrada:

```
3
```

Saída:

```
0 1 2
1 2 3
2 3 4
```

---

### Exercício 5 – Contador de vogais por palavra

Peça palavras ao usuário até ele digitar "fim".

Para cada palavra:

* conte quantas vogais ela possui
* exiba o resultado

Exemplo:

Entrada:

```
casa
python
fim
```

Saída:

```
casa -> 2 vogais
python -> 1 vogal
```

---

### Exercício 6 – Comparação entre listas

Peça ao usuário:

* 3 números para lista A
* 3 números para lista B

Compare posição por posição.

Exemplo:

Entrada:

```
Lista A: 5 3 8
Lista B: 4 3 10
```

Saída:

```
Posição 1: A é maior
Posição 2: iguais
Posição 3: B é maior
```

---

### Exercício 7 – Padrão alternado

Peça um número N.

Exiba um padrão com N linhas e 2 colunas, alternando `*` e `-`.

Exemplo 1:

Entrada:

```
2
```

Saída:

```
*-
-*
```

Exemplo 2:

Entrada:

```
3
```

Saída:

```
*-
-*
*-
```

---

### Exercício 8 – Padrão numérico com repetição

Peça um número N.

Exiba o seguinte padrão:

Exemplo:

Entrada:

```
4
```

Saída:

```
1
22
333
4444
```
